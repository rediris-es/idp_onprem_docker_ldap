## Información sobre la configuración SSL

Este directorio va a contener los certificados SSL para el NGINX que se utiliza en idp_onprem_docker_ldap:
- cert_web.crt
- cert_web.key

Se adjuntan unos certificados autofirmados de prueba para el CN idp.prueba.test que en caso de no utilizar el script init_script.sh permiten usar el IDP con la configuración básica.
